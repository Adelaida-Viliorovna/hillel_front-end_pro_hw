Картка користувача

Створіть об'єкт, що містить інформацію про користувача, таку як ім'я, вік, місце проживання тощо. Створіть метод об'єкту для отримання та відображення цих даних.

Скрипт:

                
        let user = {
            name: "Северин",
            age: 34,
            location: "Київ",
            profession: "Касир",
            getInfo: function(){
                return `Name: ${this.name}, Age: ${this.age}, Location: ${this.location}, Profession: ${this.profession}`
            }
        };
        
        console.log(user.getInfo());
